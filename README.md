📚 AppStreamingHQs

Aplicativo de streaming de histórias em quadrinhos (HQs), para ler quadrinhos digitais de forma prática, direto no dispositivo.

⚠️ Nota: os trechos marcados com [PREENCHER] dependem de informações do projeto que precisam ser ajustadas por você.

📖 Sobre o projeto

O AppStreamingHQs permite que o usuário navegue por um catálogo de HQs, escolha um título e leia os capítulos online, sem precisar baixar arquivos.
